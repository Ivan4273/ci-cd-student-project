# CI/CD Student Project

![CI Status](https://github.com/Ivan4273/ci-cd-student-project/actions/workflows/ci.yml/badge.svg)

Простой проект для демонстрации CI/CD pipeline с автоматическим тестированием.

## Что внутри

- `src/calculator.py` — класс Calculator с методами add, subtract, multiply, divide, power
- `tests/test_calculator.py` — тесты на pytest
- `.github/workflows/ci.yml` — CI pipeline (test, lint, security)
